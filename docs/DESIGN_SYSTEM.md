# xTranslator 设计系统

## 已选品牌方向

已选用 Product Design 的“玻璃丝带 x”方向。概念稿见 [logo-glass-ribbon-selected.png](assets/logo-glass-ribbon-selected.png)。该 PNG 是品牌方向参考，不可直接当作所有尺寸的生产图标；实现前需从此方向产出清晰的 16、32、48、128 像素扩展图标和浅/深色版本。

图形标记由两条圆润、半透明的玻璃丝带交叉组成抽象小写 `x`：青蓝代表输入语言，紫蓝代表目标语言，交叉区域代表语境融合。字标固定为 `xTranslator`，使用中性无衬线字体；`x` 可使用品牌强调色，其余文字使用前景色。

Logo 是独立品牌资产，不受图标库限制。应用内功能图标需按需集成到 `src/shared/icons/index.ts`（本仓库内联已用图标，不依赖图标库），不得手写 SVG、复制 SVG 或使用 emoji 代替图标。

## 视觉原则

采用 macOS 玻璃拟态：层次由半透明材质、背景模糊、细描边和克制阴影表达，而不是大面积卡片、厚边框或渐变背景。插件是 YouTube 观看页上的轻量辅助层，默认不遮挡人物、字幕或播放器原控件。

玻璃效果用于浮层、菜单、Popup 头部与状态面板、设置页头部与设置面板以及选中状态；正文阅读区必须保持足够实的背景，以保证长字幕和评论译文可读。视频字幕使用一个约 62% 透明度的黑色紧凑卡片，译文与原文共享底板，不能让文字透明。

Popup 与设置页使用浅色 macOS 玻璃：页面底色由冷色渐变和青蓝/紫色柔和光晕组成，内容面板使用半透明白色材质、24px 背景模糊、白色高光描边和克制阴影。输入框、下拉框和翻译记录使用更实的次级玻璃层；Toast 使用深色玻璃以保证对比度。

## Popup 与设置页实现约定

- 静态页面与样式的源文件位于 `public/popup/`、`public/options/` 和 `public/styles/`；根目录下的 `popup/`、`options/`、`styles/` 是 `pnpm build` 生成的扩展产物，不直接编辑。
- Popup 宽度固定为 328px；设置页内容宽度上限为 640px，最小宽度为 480px，并且不得产生横向溢出。
- 玻璃层必须同时提供半透明背景和 `backdrop-filter: blur(24px)`；不支持背景模糊时，半透明材质仍需保证文字可读。
- 所有输入框、下拉框、按钮都必须有可见键盘焦点；设置页字段继续自动保存，不因视觉改版恢复手动保存按钮。
- hover/浮起动效使用快速时长；`prefers-reduced-motion: reduce` 时关闭过渡与不必要的位移动效。

## 状态与无障碍

- 所有功能图标都必须有本地化 `aria-label`；图标不得成为唯一信息载体。
- 交互目标至少 32×32px，Popup 主操作至少 36px 高。
- 深色玻璃正文必须采用 `color.text.onDark`；玻璃下的正文区域不得降低到 WCAG AA 以下。
- 加载状态显示当前翻译进度，成功状态显示完成数量；播放器内不使用打断观看的 toast。设置页的模型加载和翻译服务保存状态以内联文字反馈，配置未完成时不弹全局提示；真正的保存失败和缓存删除等异常才使用 toast。
- 错误状态说明原因，提供重试与设置入口。删除缓存使用危险色并要求二次确认。
- 设置页的翻译服务使用“服务商 + API Key + 模型”三项原子保存：API Key 输入只更新草稿，点击“加载模型”并选定模型后才持久化；不同服务商分别恢复各自配置。字幕模式、划词开关和上下文选项独立自动保存；不显示手动保存按钮。
- 支持键盘焦点、Enter 触发、Esc 关闭和偏好减少动效。
- 浅色玻璃下的正文和表单控件必须保持 WCAG AA 对比度；Toast 等深色玻璃反馈使用 `color.text.onDark`，错误文字使用可读的浅红色。
